# Фронтенд: Дизайн-система и токены

Минимализм уровня Linear: высокая плотность, спокойная типографика, цвет функционален (§5.1).
**Только тёмная тема на старте**, но всё через токены → светлая/кастомные темы позже без переделок (§5.2).
Стек: Nuxt UI (Reka UI + Tailwind), токены через app config.

---

## 1. Принципы

- Цвет — функционален (статусы/приоритеты/лейблы), не декоративен.
- Минимум рамок и теней; акцент на контенте.
- Плотность как первоклассный параметр (`comfortable`/`compact`).

## 2. Токены

### Цвет (семантические)
`bg-base`, `bg-elevated`, `bg-hover`, `border-subtle`, `text-primary/secondary/tertiary`, `accent`
+ палитры `status-*`, `priority-*`, `label-*`.

> **Важно (§5.2):** статусы и лейблы хранят цвет как **ссылку на токен** (`color_token`), не hex —
> смена тем не ломает данные. Доменные таблицы уже несут `color_token` (teams-config).

### Типографика
- Один гротеск (Inter / системный стек).
- Шкала: 12 / 13 / 14 / 16 / 20 / 24; межстрочные под плотные списки.

### Spacing / радиусы / тени
- Шкала 4-pt; радиусы 4–6px; тени почти не используются (только overlay/popover).

### Иконки
- Один монохромный набор, `currentColor`.

### Плотность
- `comfortable` / `compact` → высота строк списков; параметр View (`options.density`) и дефолт воркспейса.

## 3. Реализация

- Токены — в Nuxt UI app config + Tailwind theme; компоненты ссылаются на семантические имена, не на сырые значения.
- Тёмная тема зашита; светлая — вне скоупа MVP, но структура токенов её допускает (не хардкодим цвета в компонентах).

## 4. Доступность (§5.7)

- Клавиатурная навигация по всем элементам; фокус-менеджмент в модалках/меню.
- ARIA-роли (особенно DataGrid, Tree, Menu, Command) — база от Reka UI/Nuxt UI.
- Контраст WCAG AA; уважение `prefers-reduced-motion`.
- Проверяется axe-core в E2E (§10.1).

## 5. Адаптивность (§5.6)

- Десктоп-first. Узкие ширины: контекстный сайдбар → overlay, правый панель деталей → выезжающая панель.
- Полноценный мобильный клиент — за рамками первых версий; компоненты проектируются с прицелом на переиспользование.

## Открытые микро-вопросы

- Точные hex-значения палитры тёмной темы — на этапе визуального дизайна (M8 polish).
- Набор иконок (Lucide и т.п.) — финализировать в [components](components.md).
